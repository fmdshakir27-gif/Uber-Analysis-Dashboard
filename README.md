Uber Trip Analysis Dashboard 🚕📊

An interactive Power BI dashboard analyzing Uber trip data — covering bookings, revenue, trip distance, payment types, vehicle performance, and location trends — to uncover actionable insights for business decision-making.


📌 Overview

This project presents a multi-page Power BI report built on Uber trip data for the period 01-06-2024 to 30-06-2024. It provides a 360° view of ride bookings across the city, helping stakeholders track performance, identify demand patterns, and understand customer/vehicle preferences.

The dashboard includes three pages:

Overview Analysis — high-level KPIs and trends (this view)
Time Analysis — time-based breakdown of bookings
Details — granular, drill-through level data
